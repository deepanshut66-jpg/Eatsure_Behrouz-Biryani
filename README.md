# EatSure UAE and Behrouz Biryani

All files are in one folder. Keep them together.

## GitHub and Render
1. Extract the ZIP and upload ALL extracted files to your GitHub repository root, then commit. Do not upload the ZIP itself.
2. In Render, choose New > Static Site and connect the repository.
3. Branch: main. Root Directory: leave blank. Build Command: true. Publish Directory: .
4. Create Static Site.

Alternatively choose New > Blueprint; render.yaml contains the settings.

Main app: index.html. Mobile showcase: mobile.html. Brand landing page: behrouz.html.

This is an academic concept prototype. Checkout simulates an order and does not process payments or submit live orders. Menu prices, servings and delivery estimates are illustrative. Packaging models are visual concepts, not manufacturing specifications. Asset attribution is in sources.json.
